## 操作

Windows 自带多桌面，不用装任何软件：

| 快捷键 | 作用 |
| --- | --- |
| `Win + Ctrl + D` | 新建一个虚拟桌面并直接切过去 |
| `Win + Ctrl + ← / →` | 在桌面之间左右切换 |
| `Win + Ctrl + F4` | 关闭当前桌面（窗口自动并入左边那个） |
| `Win + Tab` | 任务视图：总览所有桌面、拖动窗口跨桌面分配 |

典型摆法：桌面 1 写代码、桌面 2 查资料开会议、桌面 3 放摸鱼窗口——`Ctrl + Win + ←` 一秒清场，比 Alt+Tab 翻窗口体面得多。

## 注意事项

- Windows 11 可以给每个桌面设**不同壁纸**（任务视图里右键桌面），一眼认出自己在哪桌。
- 任务栏默认只显示当前桌面的窗口，切桌即"清场"；想让所有窗口常驻任务栏，去 设置 → 系统 → 多任务处理 里改。
- 重启后桌面布局会被记住，但各窗口的归位情况取决于应用自己，别当成持久工作区来依赖。
