## 操作

1. 桌面（或任意目录）右键 → 新建 → 文件夹；
2. 重命名为 `GodMode.{ED7BA470-8E54-465E-825C-99712043E01C}`，回车；
3. 文件夹图标变成控制面板样式，双击打开——里面是全部系统设置的大列表，不用在控制面板里一层层翻。

这个 trick 从 Windows Vista 时代就存在。名字里的 `GodMode` 部分可以随便改（`设置大全.{ED7BA470-…}` 一样有效），关键是**英文句点 + 花括号里的 CLSID**：它让资源管理器把这个文件夹解析成对应的系统组件。

同一原理还能换别的 CLSID 玩：

| CLSID | 变成什么 |
| --- | --- |
| `{ED7BA470-8E54-465E-825C-99712043E01C}` | 全部控制面板项（实测 199 个入口） |
| `{645FF040-5081-101B-9F08-00AA002F954E}` | 回收站 |
| `{20D04FE0-3AEA-1069-A080-002B30309D}` | 此电脑 |

还有人拿回收站 CLSID 给普通文件夹改名：双击进去显示的是回收站界面，原文件被"藏"在壳里——早年间流行的"文件夹加密"障眼法。

## 注意事项

- 它只是**设置入口的聚合**：点开某项还是走原设置页，该重启生效的照样重启。
- 伪装文件夹是障眼法不是加密：把名字改回去就能看到内容，别用它保护真机密文件；删除伪装文件夹会连内容一起删。
- 公司域控锁死的机器上部分设置项点不开，是策略限制，不是文件夹失效。
- 实测环境 Windows 11（build 26300），枚举到 199 个入口，不同版本数量略有出入。
