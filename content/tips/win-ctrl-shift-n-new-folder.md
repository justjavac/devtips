## 操作

在资源管理器里按 `Ctrl + Shift + N`：

1. 当前目录立刻多出一个新建文件夹，且**已处于命名状态**，直接打字、回车确认；
2. 连续建仓：`Ctrl + Shift + N` → 输名 → 回车 → 再 `Ctrl + Shift + N`……整理项目素材时，一整层目录结构一分钟搭完。

## 注意事项

- 误建了 `Ctrl + Z` 一键撤销。
- 组合键**跨软件含义不同**：Edge / Chrome 里 `Ctrl + Shift + N` 是新建 InPrivate / 隐身窗口——在浏览器里按了可别纳闷文件夹去哪了。
- 焦点得在资源管理器窗口里；在桌面按无效。
