## 操作

1. `Win + G` 打开 Xbox Game Bar；
2. 在"捕获"小组件点录制按钮，或直接 `Win + Alt + R` 开始 / 停止；
3. 录好的 MP4 存在 `此电脑 → 视频 → 捕获`，还会贴心地按应用分文件夹。

另一个隐藏功能：`Win + Alt + G` 录制**刚过去的 60 秒**——游戏里打出神操作立刻按它，回溯保存。

Windows 11 的截图工具（`Win + Shift + S`）也内置了屏幕录制：框选区域即可录，还能覆盖桌面和资源管理器。

## 注意事项

- Game Bar 主要面向应用窗口；桌面和资源管理器不在范围内（用截图工具的录屏补）。
- 分辨率、帧率、麦克风在 设置 → 游戏 → 捕获 里调。
- 已实测：本机 Xbox Game Bar（GamingOverlay）组件存在且状态正常。
