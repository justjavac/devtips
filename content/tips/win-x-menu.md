## 操作

`Win + X` 呼出"高级用户菜单"，弹出后直接敲字母：

| 组合 | 打开 |
| --- | --- |
| `Win + X` → `T` | 任务管理器 |
| `Win + X` → `A` | Windows 终端（管理员） |
| `Win + X` → `U` → `U` | 关机 |
| `Win + X` → `U` → `R` | 重启 |
| `Win + X` → `M` | 设备管理器 |
| `Win + X` → `K` | 磁盘管理 |

菜单里每项都带下划线字母提示，看两遍就有肌肉记忆——设备管理器、磁盘管理、终端管理员全在两层按键以内。

## 注意事项

- 字母是菜单助记键，必须在菜单弹出后再按。
- Windows 11 直接右键开始按钮也能调出同一菜单。
- 配合 `Win + E`、`Win + I`，常用系统功能几乎全键盘可达。
