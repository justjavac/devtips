## 操作

在资源管理器右上角搜索框输入（中文冒号即可，支持中英文关键词）：

| 过滤条件 | 效果 |
| --- | --- |
| `大小:巨大` | 大于 128MB 的文件 |
| `大小:>500MB` | 大于 500MB |
| `修改日期:本周` | 本周改动过的 |
| `类型:视频` | 按类型筛 |
| `*.log 修改日期:>2026-01-01` | 多条件组合 |

非索引位置同样生效，找 C 盘里的大文件比装第三方清理工具更直接。

## 注意事项

- 点搜索框后会出现"搜索选项"按钮，可视化选择条件，不用背语法。
- 全盘搜索要点时间，先缩小路径范围更快。
- 与"设置 → 系统 → 存储 → 清理建议"（按大小列文件）互为补充。
