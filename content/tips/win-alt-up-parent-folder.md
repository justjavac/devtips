## 操作

| 快捷键 | 行为 |
| --- | --- |
| `Alt + ↑` | 去当前文件夹的**上一级**（按目录层级） |
| `Alt + ←` | 后退：回到**上一次浏览过的位置**（按历史） |
| `Alt + →` | 前进：撤销刚才那次后退 |

场景：跟着教程地址栏跳进 `C:\Windows\System32` 翻了半天，`Alt + ←` 一步回到之前的工作目录；而 `Alt + ↑` 只会把你扔到 `C:\Windows`——两个键一个走"历史"、一个走"层级"，用错地方就会迷路。

## 注意事项

- 从"搜索结果"或"快捷方式跳转"进来时，后退是回原位，上级是换地方，出发之前想清楚。
- 键盘党三连：`Alt + D` 输路径去任意处，`Alt + ↑` 逐层上溯，`Alt + ←` 沿历史回撤，全程不碰鼠标。
