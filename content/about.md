## 这个站是做什么的

DevTips 面向所有开发者，收录"看完立刻能用"的实用技巧。选题不设边界：Git、CLI、编辑器、浏览器、网络、运行时……现阶段开发者普遍在用 AI 编程工具，所以 AI 相关内容会占相当一部分，但这里不是 AI 专栏——工具会换，"用好工具"这件事不会过时。

- 每条技巧 1–3 分钟读完，看完立刻能用；
- **每条 tip 都经过实机验证**，并标注适用工具版本和实测日期；
- 偏爱冷门但实用的选题：大家都在写的常识不凑数，少有人知却能真省时间的才值得收录。

## 为什么强调"实测日期"

开发工具的迭代以周计——AI 编程助手如此，浏览器、编辑器、运行时也一样——几个月前的教程今天可能已经失效。本站每条技巧右上角的绿色徽章，记录了它最后一次在真实环境中验证通过的日期与工具版本。日期越近，越值得放心照抄。

确认失效的技巧不会被删除——顶部会出现黄色失效横幅并注明失效版本，因为失效内容本身也有搜索流量和考古价值。

## 投稿

所有内容托管在 GitHub 仓库中，欢迎通过 Pull Request 投稿：

1. 每条技巧一个 Markdown 文件，放在 `content/tips/` 下，frontmatter 字段与现有文章保持一致；
2. 写完必须**实机验证**，并如实填写 `verifiedAt`（实测日期）与 `toolVersion`（验证时的工具版本）；
3. 正文遵循"问题 → 方案 → 可复制的配置/命令 → 注意事项"结构；
4. 发现某条技巧已失效，不必删文——开 Issue 报告即可，维护者会加上失效横幅。

投稿入口与 Issue 模板见页脚的 GitHub 链接。

## 技术栈

本站为纯静态站点：Rsbuild 构建资产、Tailwind CSS v4 + Basecoat（shadcn 设计系统）负责样式、原生 JavaScript 实现交互，内容在构建期由 Markdown 渲染为 HTML。每篇技巧都提供同路径的 `.md` 版本，方便直接喂给 AI 工具。
